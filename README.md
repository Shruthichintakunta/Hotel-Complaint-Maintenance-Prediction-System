# Hotel-Complaint-Maintenance-Prediction-System
A smart hotel management system that allows guests to report complaints and uses prediction to prioritize maintenance issues efficiently.
##Abstract
The **Hotel Complaint and Maintenance Prediction System** is a Flutter-based application that helps hotels manage guest complaints easily. Guests can submit complaints about issues like AC, water, electricity, Wi-Fi, etc. The system stores and tracks complaints and predicts their **priority as Low, Medium, or High**. Maintenance staff can view complaints, update their status, and resolve them. The system helps hotels respond faster, reduce manual work, and improve guest satisfaction.
